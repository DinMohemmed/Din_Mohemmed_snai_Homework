Question Title: Execute a Python Script directly

Question_id:https://my.newtonschool.co/playground/code/mepmefz373b4?lecture_hash=t5qc0u6ap8tg

solution:

which python3
echo '#!/usr/bin/env python3' > hello.py
echo 'print("Hello from Python")' >> hello.py
chmod +x hello.py
./hello.py

Approach:
1. I found the PATH variable for Python using which command.
2. I added two lines containing the shebang operator line for Python3 and the print command to print the input.
3. I set the permissions of hello.py to executable and executed it.
