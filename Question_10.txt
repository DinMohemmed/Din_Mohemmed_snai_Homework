Solution:

cd client-app
git init
echo "Hi!" >> index.html
echo "Hello!" >> app.js
git add index.html app.js
git commit -m "Initial client files"
git remote add origin https://github.com/startup/client-app.git
git push -u origin main 
git log

Approach:
1. After navigating into the client-app directory, I initialized git inside it.
2. I also modified the contents of index.html and app.js
3. Then I added the two files to the staging area and committed them with a message "Initial client files"
4. I created a GitHub repo online and connected my local repo to it.
5. Then I pushed the main branch of my repo to the public repo.
