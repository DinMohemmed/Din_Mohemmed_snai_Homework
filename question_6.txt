Solution:

which bash
echo "#!/usr/bin/bash" > build.sh
echo "gcc hello.c -o hello" >> build.sh
chmod +x build.sh
./build.sh

Approach:
1. I found the PATH variable for bash using the which command.
2. I added the two lines containing the shebang operator line for bash and the gcc command to make hello.c executable.
3. I set the permissions of build.sh to executable and executed it.
